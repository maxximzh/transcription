Транскрибация аудио

Локальный файл → OpenRouter (transcription API) → текст на этой странице. Ключ и файл никуда не отправляются, кроме API OpenRouter. Всё работает в браузере.

01 · Ключ API
Ключ хранит менеджер паролей браузера. При запуске транскрибации браузер предложит сохранить ключ. Получить ключ: openrouter.ai/keys
02 · Файл
